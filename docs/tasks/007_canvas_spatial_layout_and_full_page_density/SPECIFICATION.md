## 2. Калибровка параллакс-скролла

```javascript
// Коэффициент смещения платы при скролле страницы
const scrollFactor = 0.40; 
targetScrollY = window.scrollY * scrollFactor;
currentScrollY += (targetScrollY - currentScrollY) * 0.08;
```

При длине лендинга в районе 9000–12000px физического скролла:
$12000\text{px} \times 0.40 = 4800\text{px}$ хода платы.  
Это идеально совпадает с виртуальной высотой платы ($5400\text{px}$), так что все 4 процессорных сердца и периферийные шлюзы последовательно и гармонично проплывают через экран до самого подвала!
