# Требования к задаче 011: Авто-карусель команды и калибровка первого экрана (Hero)

---

## Часть 1. Бесконечный авто-скролл фото команды инженеров (Карусель)

### 1.1. Контекст и бизнес-цель
В блоке команды (`TeamAndExpertise.jsx`) в левой колонке вместо статичного фото инженера внедрена бесконечная авто-карусель из трёх фотографий:
1. Текущее фото инженера за мониторами (`engineer_contact.jpg`).
2. Фото команды за проектированием (`team_slide_2.jpg` из загрузок №3).
3. Фото команды разработки (`team_slide_3.jpg` из загрузок №4).

### 1.2. Функциональные требования
- Порядок показа: `1 ➔ 2 ➔ 3 ➔ 1 ➔ 2 ➔ 3...` (строго по кругу, без отката назад).
- Интервал переключения: 3.5 секунды.
- Плавность перехода: мягкий crossfade (`opacity` с `duration-700`) и лёгкий зум `scale`.
- Индикация: 3 полоски-индикатора в верхнем правом углу с возможностью клика.
- Пауза автоскролла при наведении курсора (`hover:pause`).

---

## Часть 2. Калибровка Hero-блока: 3 ключевых экшена и сохранение просторной геометрии

### 2.1. Контекст изменений
- На первом экране (Hero) подзаголовок должен явно отражать **три последовательных действия (экшена)**:
  1. *Настройка и донастройка инфраструктуры 1С и Битрикс24.*
  2. *Интеграция автономных ИИ-агентов поверх выстроенных процессов компании.*
  3. *Работа через штатные API (устранение ручного ввода первички, ускорение смет, связь с базами).*
  4. *Сроки: запуск первого рабочего модуля — от 14 до 30 дней.*
- Кнопка *«Примеры решений»* убирается с первого экрана, при этом **вертикальные отступы и широкая геометрия Hero сохраняются в полном объёме**, чтобы блок не сжимался и не сдвигал следующий контент к чипу печатной платы (PCB Canvas).

### 2.2. Требования к копирайтингу Hero
```jsx
<p className="text-zinc-200 font-medium">
  Настраиваем и донастраиваем инфраструктуру 1С и Битрикс24.
</p>
<p className="text-zinc-300">
  Интегрируем автономных агентов поверх выстроенных бизнес-процессов компании.
</p>
<p className="text-zinc-400">
  Работаем через штатные API: убираем ручной ввод первички, ускоряем расценку смет и подключаем ассистентов к базам данных.
</p>
<p className="text-sky-300 font-medium text-sm sm:text-base pt-2">
  Запуск первого рабочего модуля — от 14 до 30 дней.
</p>
```

## 3. Критерии приемки (DoD)
- Карусель работает циклично (3.5 сек, 3 слайда).
- В Hero сформулированы 3 твёрдых действия + срок запуска.
- Кнопка «Примеры решений» убрана, высота и отступы Hero сохранены.
- Сборка `npm run build` проходит без ошибок.
- Изменения зафиксированы в Git и отправлены на GitHub Pages.
