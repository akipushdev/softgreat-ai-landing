# Требования к задаче 011: Бесконечный авто-скролл фото команды инженеров (Карусель)

---

## 1. Контекст и бизнес-цель
В блоке команды (`TeamAndExpertise.jsx`) в левой колонке в настоящий момент отображается статичное фото инженера за мониторами.
Для усиления доверия, демонстрации реальной инженерной среды и оживления интерфейса требуется сделать бесконечную авто-карусель из трёх фотографий:
1. Текущее фото инженера за мониторами (`engineer_contact.jpg`).
2. Фото из загрузок №3 (`premium_photo-1661371243525-d02768a7feee.avif` ➔ `team_slide_2.jpg`).
3. Фото из загрузок №4 (`photo-1690383682965-faf2cf669634.avif` ➔ `team_slide_3.jpg`).

---

## 2. Функциональные требования
1. **Порядок показа:**
   - 1-й слайд: фото инженера за мониторами (`engineer_contact.jpg`).
   - 2-й слайд: фото команды за проектированием (`team_slide_2.jpg`).
   - 3-й слайд: фото команды разработки (`team_slide_3.jpg`).
2. **Цикличность:**
   - Строго по кругу: `1 ➔ 2 ➔ 3 ➔ 1 ➔ 2 ➔ 3...` (без отката назад).
3. **Интервал переключения:**
   - Автоскролл с комфортным рейтом 3.5 секунды.
4. **Плавность перехода:**
   - Мягкий crossfade (`opacity` с `duration-700`) и лёгкий зум `scale`, исключающий рывки верстки.
5. **Индикация и управление:**
   - Тонкие полоски-индикаторы (progress dots/bars) внизу фото, показывающие активный слайд.
   - Возможность ручного клика по индикаторам для мгновенного перехода.
   - Пауза автоскролла при наведении курсора (`hover:pause`).

---

## 3. Критерии приемки (DoD)
- Все 3 изображения оптимизированы и подключены в `src/assets/images/`.
- Карусель работает плавно, циклично по кругу с интервалом 3.5 секунды.
- Сборка `npm run build` проходит без ошибок.
- Изменения зафиксированы в Git и отправлены на продакшн GitHub Pages.
