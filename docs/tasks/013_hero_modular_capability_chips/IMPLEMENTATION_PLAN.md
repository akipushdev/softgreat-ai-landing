# IMPLEMENTATION PLAN: Задача 013 — Модульные микрочипы на Hero

> **Статус:** 📋 Запланировано (Ждёт явной команды на запуск)  
> **Оценка времени:** 15–20 минут после утверждения  
> **Ключевой файл:** `src/components/Hero.jsx`

## Этапы реализации (только после аппрува пользователя)

### Этап 1: Подготовка иконного сета и структуры данных
- Импорт иконок из `lucide-react`:
  - `FileSpreadsheet` / `Receipt` (Первичка в 1С)
  - `Calculator` / `FileSpreadsheet` (Расценка смет)
  - `Bot` / `Headset` (Клиентский сервис 24/7)
  - `Truck` (Логистика и рейсы)
  - `Scan` / `Eye` (Компьютерное зрение)
- Определение массива чипов с короткими названиями и выгодами.

### Этап 2: Верстка блока в `Hero.jsx`
- Замена монолитного параграфа:
  1. Вводный разделитель: два чётких шага («Настройка 1С/Битрикс24» → «Интеграция ИИ-агентов»).
  2. Горизонтальная сетка 5 микрочипов с аутентичными ножками (SMD pin pads) и эффектом подсветки при наведении.
  3. Нижняя плашка срока запуска: `Запуск первого рабочего модуля — от 14 до 30 дней`.

### Этап 3: Проверка адаптивности и отступов
- Проверить отображение на разрешениях: Mobile (375–420px), Tablet (768px), Desktop (1280–1920px).
- Проверить визуальное взаимодействие с `MicroprocessorCanvas` (отсутствие наложения на верхние дорожки и чипы).

### Этап 4: Сборка и деплой
- Запуск `npm run build` для проверки отсутствия ошибок сборки.
- Коммит в Git и отправка на GitHub Pages.
- Проверка live-версии на https://aipush.dev/softgreat-ai-landing/.
