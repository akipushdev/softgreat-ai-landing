# Спецификация 006: Топология микропроцессорного кластера и параллакс-скролл

---

## 1. Реестр технологических узлов (Чипов) печатной платы

Плата объединяет все ключевые компоненты корпоративного ИИ-стека SFTG AI:

### Эшелон 1 (Верхний — Вход данных и Облачные LLM):
1. **ЯНДЕКС GPT / GEMINI / CHATGPT** (Центральный процессор №1, Cloud LLM, быстрый отклик и минимальная стоимость).
2. **1С:ПРЕДПРИЯТИЕ** (Шлюз OData / REST API).
3. **БИТРИКС24 CRM** (Шлюз сделок и открытых линий).
4. **TELEGRAM / MAX** (Интерфейс чат-ботов для сотрудников и клиентов).
5. **МОЙСКЛАД** (Складской учет и отгрузки).

### Эшелон 2 (Средний — On-Premise контур и Тонкая настройка):
6. **ON-PREMISE LLM · QWEN 2.5 / LLAMA 3.3** (Центральный процессор №2, Локальное развертывание, 152-ФЗ РФ и 99-З РБ).
7. **LORA / QLORA АДАПТЕРЫ** (Дообучение весов под отраслевые регламенты и номенклатуру заказчика).
8. **RAG / СЕМАНТИЧЕСКИЙ ПОИСК** (Векторный поиск по корпоративным базам знаний и нормативным актам).

### Эшелон 3 (Нижний — Данные и Оркестрация):
9. **POSTGRESQL / PGVECTOR** (Реляционное хранилище и эмбеддинги документов).
10. **PYTHON CORE ENGINE** (Оркестрация агентов, планировщики, Fast/Async API).
11. **VISION OCR УЗЕЛ** (Распознавание сканов УПД, ТТН, накладных и синих печатей).

## 2. Кинематика параллакса

- Виртуальная высота платы: `totalHeight = Math.max(height * 2.8, 3000)`.
- Демпфирование:
  ```javascript
  const scrollFactor = 0.35;
  targetScrollY = window.scrollY * scrollFactor;
  currentScrollY += (targetScrollY - currentScrollY) * 0.08;
  ```
- Отрисовка с учетом `currentScrollY` и отсечение невидимых сегментов.
- Курсор мыши: `boardMouseY = mouse.y + currentScrollY`.
