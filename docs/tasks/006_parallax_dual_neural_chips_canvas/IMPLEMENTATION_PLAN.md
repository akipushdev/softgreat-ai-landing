# План реализации задачи 006: Параллакс-скролл и двойной кластер микросхем

---

## Шаг 1. Топологическая модель расширенной печатной платы
- В `MicroprocessorCanvas.jsx` расширить генерацию платы в вертикальное пространство (виртуальная высота платы `totalBoardHeight = Math.max(height * 2.5, 3200)`).
- Сконфигурировать 2 главных нейро-процессора:
  1. `ОБЛАЧНЫЕ LLM · ЯНДЕКС GPT / GEMINI` (в верхнем эшелоне Hero).
  2. `СУВЕРЕННЫЕ LLM · QWEN 2.5 / LLAMA 3.3` (в среднем эшелоне Архитектуры/Решений).
- Расставить соединяющие шины передачи данных между облачным и суверенным процессорами, шлюзами 1С/Битрикс24 и базой данных.

## Шаг 2. Механика плавного параллакса (Lerp & Viewport Culling)
- Добавить слушатель `scroll` с passive-опцией.
- В методе `render` реализовать плавное сглаживание:
  `scrollY += (targetScrollY - scrollY) * 0.08`
- Реализовать отсечение элементов (culling), находящихся далеко за пределами видимого вьюпорта, для сохранения 60 fps.

## Шаг 3. Адаптация интерактивных световых импульсов и курсора мыши
- Корректно связать координаты мыши с виртуальной системой координат платы.
- Проверить, что световые импульсы текут плавно при скролле вверх и вниз.

## Шаг 4. Верификация и сборка
- Проверить плавность скролла в десктопном и мобильном режимах.
- Проверить сборку `npm run build`.
- Обновить рабочий прогресс и зафиксировать коммит.
