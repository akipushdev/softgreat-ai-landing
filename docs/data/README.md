# Общая база знаний и ресурсы проекта (docs/data)

В этой папке собрана вся агрегированная аналитическая и практическая информация проекта **SFTG AI**:

1. [MARKET_RESEARCH_SUMMARY.md](./MARKET_RESEARCH_SUMMARY.md) — Сводный анализ лидеров рынка B2B AI (РФ и РБ), модели ценообразования, карта болей клиентов и архитектура безопасности.
2. [B2B_USE_CASES_CATALOG.md](./B2B_USE_CASES_CATALOG.md) — Полный каталог 15 прикладных B2B-кейсов по 4 контурам (Документы, Продажи, Склад/ВЭД, Управление) с оцифрованными результатами и метриками.

Вся информация очищена от внутренних персональных заметок и готова для использования разработчиками, маркетингом и отделом продаж.
