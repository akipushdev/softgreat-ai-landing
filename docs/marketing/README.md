# Папка для контента и идей: Коммерческий отдел (Маркетинг и Продажи)

Добро пожаловать в репозиторий проекта **SFTG AI**!

Эта папка создана специально для отдела маркетинга и продаж. Здесь мы собираем идеи, формулировки офферов, описания болей клиентов, кейсы и гипотезы для сайта и рекламных кампаний.

---

## Как маркетологу вносить идеи и тексты:

1. **Создайте новый файл в этой папке:**
   - Например: `offer_b2b_logistics.md`, `pain_points_accounting.md`, `case_grand_smeta.md`.
2. **Пишите в свободной форме или используйте шаблон:**
   - Какая боль у клиента?
   - Как её решает наш ИИ-модуль?
   - Какой оцифрованный результат (экономия часов, денег, снижение ошибок)?
3. **Использование ИИ-ассистентов (Claude Code / ChatGPT / Cursor):**
   - Вы можете использовать любого ИИ-ассистента для генерации и редактирования текстов прямо в репозитории.
4. **Флоу ревью и публикация:**
   - Создайте pull request или просто отправьте файл на ревью Александру и Юлиану.
   - Мы проверим техническую реализуемость формулировок и перенесём утверждённый контент в вёрстку сайта.
