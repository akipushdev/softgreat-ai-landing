# Архитектурная спецификация и ТЗ: Мультиагентный ИИ-сканер сайтов (Live AI Audit)

> **Назначение:** Техническое задание на разработку интерактивного сервиса экспресс-аудита бизнеса клиента прямо на лендинге `sftg.by`.  
> **Инициатор и Главный архитектор:** Александр Кирилов (Head of AI / Chief AI Architect).  
> **Статус:** В очереди разработки (Sprint Q4 2026).  
> **Стек:**  
> - **Фронтенд:** React 18 + Vite + Tailwind CSS (`softgreat-ai-landing`, GitHub Pages / `sftg.by`).  
> - **Бэкенд:** Python (FastAPI + LangGraph / Asyncio orchestration) на VPS.  
> - **Протокол доставки:** Server-Sent Events (SSE / Streaming) для живого появления карточек.  
> - **Безопасность:** Cloudflare Turnstile, CORS, Rate Limit по IP, кэширование в SQLite.

---

## 1. Концепция и бизнес-цель

Посетитель сайта (руководитель компании в РБ/РФ) вводит домен своего бизнеса (например, `centrd17.by`, `alfasb.by`, `salatoria.by`).  
Вместо статичной формы «Оставьте телефон, мы вам перезвоним», система в прямом эфире за 3–5 секунд:
1. Сканирует специфику бизнеса (услуги, товары, география, каталоги).
2. Запускает параллельную мультиагентную экспертизу (B2C-продажи, B2B-документооборот, склад/производство).
3. Потоково (через SSE) выводит на экран **интерактивный чек-лист с готовыми сценариями ИИ-автоматизации**, расчётом сэкономленных часов и кнопкой записи на живой тест-драйв.

## 2. Архитектура системы (Separation of Concerns)

```
[Посетитель на https://sftg.by] (React SPA на GitHub Pages)
                 │
                 │ 1. Ввод URL сайта + чекбоксы (1С / Битрикс24)
                 │ 2. Cloudflare Turnstile токен (защита от ботов)
                 │ 3. SSE-подключение (GET /api/v1/audit/stream?url=...)
                 ▼
[API Gateway: Nginx на VPS] (CORS whitelist: https://sftg.by)
                 │
                 ▼
[FastAPI Backend + LangGraph State Machine]
                 │
                 ├───────────────────────────────┐
                 ▼                               ▼
     [Агент-Краулер (Scraper)]        [Кэш проверок (SQLite)]
     (Быстрый fetch главной,          (Если домен уже проверялся —
      цен, услуг, контактов)           мгновенная отдача за 0.05 сек)
                 │
                 ▼
     [Мультиагентный оркестратор LangGraph]
                 │
      ┌──────────┴──────────┐
      ▼                     ▼
[B2C Sales Agent]    [B2B Ops & 1C Agent]
(Квалификация,       (Первичка, накладные,
 мессенджеры, лиды)   договоры, чек-листы)
      │                     │
      └──────────┬──────────┘
                 ▼
     [Reducer / Estimator Agent]
     (Сводит в валидный JSON-формат,
      считает часы экономии и окупаемость в BYN)
                 │
                 ▼ (Server-Sent Events)
[Потоковый рендер карточек на экране пользователя]
```

## 3. Требования к бэкенду (Python / LangGraph на VPS)

### 3.1. Пайплайн агентов в LangGraph
* **Узел 1: `fetch_site_context`** — легковесный асинхронный скрапер (`httpx` + `BeautifulSoup4` или `trafilatura`). Извлекает заголовок, meta-описание, H1–H3, пункты меню и первые 3 000 символов смыслового текста. Лимит на скачивание — 2 секунды.
* **Узел 2: Параллельные ветки экспертов:**
  * `b2c_sales_node`: анализирует входящие каналы (мессенджеры, корзины, запись на курсы/услуги).
  * `b2b_operations_node`: анализирует рутину b2b (поставки, прайс-листы, ТЗ, договоры с юрлицами, накладные).
* **Узел 3: `reducer_estimator_node`:**
  * Получает выводы двух агентов.
  * Генерирует строго типизированный список из 3–4 карточек по Pydantic-схеме.
  * Рассчитывает реалистичный диапазон экономии (часов в месяц и ориентир в BYN).

### 3.3. Безопасность и защита бюджета
1. **Cloudflare Turnstile:** валидация клиентского токена перед стартом парсинга и вызова LLM.
2. **CORS:** разрешён только `https://sftg.by` и `http://localhost:5173`.
3. **Rate Limiting:** `slowapi` — не более 3 запросов в час на 1 IP-адрес.
4. **SQLite Cache:** результаты анализа сохраняются по `domain_hash` на 14 дней. Повторные запросы отдаются с нулевым расходом токенов.

## 4. Требования к фронтенду (React в `softgreat-ai-landing`)

### 4.1. Новый компонент `LiveAiAudit.jsx`
1. **Экран ввода:**
   * Строка ввода сайта: `https://ваша-компания.by`.
   * Быстрые чекбоксы окружения: `[x] Используем 1С`, `[ ] Используем Битрикс24`.
   * Кнопка: **«Рассчитать эффект ИИ»**.
2. **Анимация сканирования (Live Log):**
   * Пока бэкенд шлёт SSE-события, в терминальном окне бегут строчки:
     * `> Подключение к alfasb.by...`
     * `> Обнаружен профиль: Системы безопасности и СКУД...`
     * `> Запуск агентов аудита документооборота и продаж...`
3. **Интерактивный конструктор выгоды:**
   * Карточки всплывают одна за другой по мере готовности.
   * Чекбоксы кликабельны: пользователь может снять/поставить галочки.
   * Динамический счётчик внизу: *«Итого выбрано: 45 часов экономии в месяц (~1 600 BYN)»*.
4. **Форма захвата лида:**
   * Кнопка **«Записаться на 20-минутное демо на ваших данных (0 BYN)»**.
   * Поле для ввода Telegram / Телефона.
   * При отправке данные летят вебхуком в Telegram-чат команды SFTG и в Битрикс24 со всеми выбранными чекбоксами.

1. **Фаза 1 (Бэкенд-прототип на VPS):**

   * Настройка Nginx и SSL (`api.sftg.by`) на VPS.
   * Подключение Cloudflare Turnstile и Rate Limiter.
