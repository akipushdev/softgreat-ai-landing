## 3. Требования к дизайну и качеству (Skill: landing-page-design)

В проекте используется скилл `.gemini/skills/landing-page-design/SKILL.md`:
- **Типографика:** Только **Geist** или **Manrope**. Запрещены Inter, Roboto, Arial, Helvetica. Никакого курсива в интерфейсе.
- **Анти-булшит копирайтинг:** Запрещены абстрактные фразы (*«революционизируем»*, *«инновационный подход»*, *«next level»*). Только конкретные факты, глаголы и оцифрованные исходы для бизнеса.
- **Цвета и стиль:** Тёмный матовый минимализм (`#000000`, `#181818`, `#1F1F1F`). Запрещены фоновые радужные градиенты. Текстовый градиент допускается только на заголовке Hero (`#FFFFFF` ➔ `#9B9B9B`).
- **Скругления (Nested Radius Formula):** $\text{внутренний радиус} = \text{внешний радиус} - \text{отступ}$.
- **Интерактивные фичи:** Эффект **Tagline Reveal** (текст ключевой мысли зажигается слово за словом при скролле).
- **Стек реализации:** Vite + Tailwind CSS (уже установлены в корне).

## 5. Регламент SDLC и структура задач (`docs/tasks/`)

1. **Задачи и артефакты (`docs/tasks/`):**
   - Все рабочие задачи и спецификации ведутся строго в папке `docs/tasks/`.
   - Именование папок строго версионируется: `001_<название>`, `002_<название>` и т.д.
   - Каждая задача содержит спецификацию требований, план реализации и результаты проверки.

2. **Разделение публичного и локального контуров:**
   - Вся документация в репозитории (`docs/`, `src/` и корневые файлы) ведётся в строго нейтральном инженерно-продуктовом стиле.
   - Любые приватные рабочие черновики или персональные заметки хранятся исключительно в папке `local/` (включена в `.gitignore` и не попадает в систему контроля версий).

3. **Архитектурная эволюция проекта:**
   - **Фаза 1 (Текущая):** Быстрый, легкий, статичный B2B-лендинг (Vite + Tailwind CSS), готовый к публикации на GitHub Pages или Nginx VPS.
   - **Фаза 2 (Перспектива):** Интеграция бэкенда (или подключение демо-сервера через API / iFrame) для запуска живых интерактивных ИИ-демонстраций прямо на сайте. Кодовая база проектируется модульно.
